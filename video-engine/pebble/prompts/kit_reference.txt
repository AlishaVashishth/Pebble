VISUAL KIT (pre-built and already available in your script; never import or redefine anything from it)

STATES (use these strings everywhere): "default" (calm blue-grey), "active" (amber: what is being looked at right now), "good" (green: found / done / correct), "bad" (red: rejected / error / bug), "dim" (faded: finished or ignored).
CONSTANTS: STAGE, LEFT_LANE, RIGHT_LANE (positions); T_FAST=0.4, T_STEP=0.7, T_SLOW=1.1 (seconds, for run_time of your own animations); colors C_TEXT, C_MUTED, C_ACCENT, C_ACTIVE, C_GOOD, C_BAD, C_BG (only for raw Manim objects).
LAYOUT ZONES (the kit enforces them, you only pick the lane): title at the top, step tag top right, stage in the middle band, chip row below the stage, caption band at the bottom with room for two wrapped lines, legend in the caption band's right corner. A structure can never enter the chip or caption band, and two structures never share the stage: the first one keeps STAGE, the second is moved to RIGHT_LANE and fitted to max_width=5.4. Forgetting at= therefore cannot overlap anything.

SCENE HELPERS (call with self; each plays its own animation):
  show_title(self, text)                       title at the top with an accent underline; one per scene, nothing else goes at the top
  title_card(self, title, subtitle=None)       opening card, scene 1 only
  beat(self, caption)                          show the caption of the current spoken sentence at the right moment; one call per narration sentence, in order
  set_caption(self, text)                      one-line caption at the bottom, crossfades the previous caption; use it only when the scene has no beats; at most 70 characters, plain words, no code
  show_legend(self)                            colour legend in the caption band's right corner (first scene that shows coloured states)
  step_tag(self, n, total)                     "Step n of total" tag, top right
  result_cards(self, answer, time, space)      closing scene: three cards (Answer, Time, Space), strings such as "[0, 1]", "O(n)", "O(n)"
  compare_panels(self, left_title, right_title, left_state="bad", right_state="good") -> (left_at, right_at)   two framed half-stage panels; build structures with at=left_at / at=right_at, max_width=5.4

STRUCTURES (each is a Mobject, add it with self.play(x.intro()) or self.add(x)). Common constructor args: at=STAGE, max_width=None, max_height=None (auto-fit by default, and always fitted inside the stage band). Common method: .intro(fast=False) -> Animation (fast=True fades in over 0.3s; use fast=True whenever a structure that already appeared in an earlier scene appears again, so scenes feel continuous and keep the same size and position).
  ArrayViz(values, label=None, show_index=True)
           optional states=["default", "good", ...] builds the array already in that state, so a scene can start where the last one ended
      .append(v)  .pop(index=-1)  .set_state(i_or_list, state)  .set_all(state)  .set_value(i, v)  .swap(i, j)
      .pointer(name, i, state="active", level=0) -> Pointer      (sits under cell i with a large label such as "i", "left", "right"; give pointers that share a cell different levels 0, 1, 2)
           Pointer: .intro()  .to(i)  .hide()          (all return an Animation; .to() slides, it never teleports)
      .window(l, r, state="active") -> Window mobject (play FadeIn(win));  .move_window(win, l, r) -> Animation
  MapViz(title, show_values=True, max_rows=6, items=())
           optional items=[("2", 0), ("7", 1)] rebuilds the keys the map should already hold; an empty map shows a friendly empty slot
      .put(k, v=None)  .hit(k)  .miss(label)  .remove(k)  .set_state(k, state)
  StackViz(title, items=(), capacity=6)     .push(v)  .pop()  .peek()  .append(v)      (push drops in from above, pop lifts out; an empty stack shows an empty slot)
  QueueViz(title, items=(), deque=False)    .enqueue(v)  .dequeue()  .push(v)  .pop()  .append(v)      (deque only: .push_front(v)  .pop_back()  .popleft()  .appendleft(v))
  LinkedListViz(values)   .set_state(i, state)  .pointer(name, i, state="active", level=0)  .relink(i, j) (arrow from node i to node j; j=None means null)  .remove(i)  .insert_after(i, v)
  TreeViz(level_order)    LeetCode level-order list, None for a missing child, e.g. [3, 9, 20, None, None, 15, 7]
      .set_state(i, state)  .set_edge(i, j, state) (parent i, child j)  .annotate(i, text, state="default")
  GraphViz(labels, edges, directed=False, layout="circle", positions=None)     edges are (a, b) or (a, b, weight)
      .set_node(label, state)  .set_edge(a, b, state)  .tag(label, text) (small text under a node such as a distance; calling again replaces it)
  GridViz(rows, row_labels=None, col_labels=None)     rows is a list of lists
      .set_state((r, c) or a list of them, state)  .set_value((r, c), v)  .link(src, dst) (dependency arrow)  .unlink()
  BarsViz(values)         .set_state(i_or_list, state)  .swap(i, j)
  HeapViz(values, mode="min")    tree and array shown together      .set_state(i, state)  .swap(i, j)
  StatePanel(items: dict, side="bottom")    variables as chips like "need = 7"; side is "bottom" (a row in the chip row), "left" or "right" (a column)
      .intro()  .update(name, value, state="active")  .set_state(name, state)

Every method returns an Animation: play one with self.play(...) or several together with self.play(a, b, c). Kit animations carry their own run_time; pass run_time= to self.play only to override.
